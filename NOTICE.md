# Data attribution

The project is designed to run on the **Brazilian E-Commerce Public Dataset by Olist**
(Kaggle: `olistbr/brazilian-ecommerce`, version 2), licensed **CC BY-NC-SA 4.0**
(attribution, non-commercial, share-alike). Thanks to Olist for releasing it.

* The dataset is **not** redistributed here. `data/` is git-ignored; see
  `docs/data-acquisition.md` for how to download it yourself.
* Figures in `docs/evidence-report.md` that were computed from the dataset are derived
  from it and carry the same attribution and licence terms.
* The CI fixture in `tests/fixtures/synth/` is independently authored synthetic data
  (generated by `tests/fixtures/make_synth.py`). It contains no Olist rows.
* The source code is under the MIT licence (see `LICENSE`); that licence does not extend
  to the dataset.
